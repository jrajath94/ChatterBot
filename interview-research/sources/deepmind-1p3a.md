## Entry 1 — Research Engineer, Round 2 ML (PASSED) — best-recovered thread
- **URL:** https://www.1point3acres.com/bbs/thread-825115-1-1.html ("DeepMind research engineer 第二轮ML过经")
- **Date:** Nov–Dec 2021. Physics PhD, 2.5 yrs MLE, LinkedIn outreach.
- ~1 hr friendly recruiter chat → R1 coding (11/11) → R2 ML "背靠背，两小时" (two back-to-back sessions, 2h): open-ended applied-ML problem on machine/fleet telemetry — "机器运转信息，比如温度、机器型号、读写load之类的信号" — design how to model/learn from this data; no NLP needed.
- Interviewer philosophy: "面试官并不在意你的背景，更在意你在你了解的领域是不是真的知识点扎实…你提到了SVM，你就应该知道SVM是什么，切忌不懂装懂" — they drill whatever you claim to know.
- Final round: HM chat; half+ time on a specific model from the resume + BQ.
- Parallel London loop (replier): "1-hour Math&Statistics 和 1-hour ML"; London reputedly harder on math (probability + linear algebra).

## Key synthesized findings
1. The famous quiz (4 oral sections — math, CS, stats, ML — 30 min each over 2h) consistently reported 2019–2022, evolving by 2022 into three 1-hour interviews (Math / ML / CS+coding) for London RE; post-2023 merger reportedly ML/AI-focused quiz for some tracks.
2. RE loops add Google-style coding (must run) and, from late 2022, ML design; RS loops add research talk + per-teammate 30-min 1:1s.
3. Verbatim question types recovered: concept-definition rapid fire (matrix rank/eigen, probability, MLE, regularization-as-prior), SVM/kernel/Bayesian-network breadth, code comprehension, open-ended applied ML from telemetry data, floating point/GIL/memory management, LC-medium/hard coding with bit manipulation.
